# 日常選物：靜態商品詢價網站

直接開啟 index.html，或以靜態伺服器提供 網站根目錄。

在 products.js 編輯商品、價格、參考庫存和 SHOP.lineId。LINE 帳號留空時詢價按鈕停用，仍可複製清單。填入官方帳號（含 @）後，按鈕開啟該帳號的 LINE 預填訊息，訪客需自行送出。

本站不收款、不建立訂單、不扣庫存、不儲存個人資料。清單只保留於本次頁面，重新整理會清空。商品及價格為示範；庫存不會跨訪客即時同步。
